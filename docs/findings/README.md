# Findings

Investigation and analysis write-ups. Distinct from the [controls](../controls/), which describe
what is in place and why; these record what was actually looked at, what was concluded, and what
the tooling got wrong.

Each entry states the observation, how it was established, the root cause, and what changed as a
result. Findings that turned out to be nothing are worth keeping — the reasoning is the artifact,
not the verdict.
